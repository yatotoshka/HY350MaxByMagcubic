# Память

← [К оглавлению](../README.md)

HY350 Max имеет 2 ГБ ОЗУ и zram. Android 14 с вендорским лаунчером и Google-сервисами живёт на грани, поэтому память здесь — не абстракция, а причина лагов и выгрузки приложений.

## Снимок на проверенном устройстве

```
$ adb shell free -m
              total        used        free      shared  buff/cache   available
Mem:           1965        1763         202          10          315         927
Swap:          1768         286        1482
```

- всего ОЗУ: 2012716 КБ (~1965 МиБ);
- `MemAvailable`: 949076 КБ (~927 МиБ);
- zram: 1768 МиБ, из них занято 286 МиБ;
- `/data`: 12 ГБ, занято ~1,5 ГБ.

Это **один снимок после загрузки**, а не бенчмарк. На другой сборке и с другим набором приложений цифры будут другими.

## Как смотреть память

```sh
# Общая картина
adb shell free -m
adb shell cat /proc/meminfo | head -10

# Кто занимает память (без root покажет не всё)
adb shell dumpsys meminfo

# Конкретное приложение
adb shell dumpsys meminfo com.example.app

# zram/swap
adb shell cat /proc/swaps
adb shell cat /sys/block/zram0/mm_stat 2>/dev/null
```

Для подробностей нужен root: без него часть `dumpsys meminfo` скрыта.

## Что отключать

Не отключайте системные компоненты, не понимая последствий. Безопасные кандидаты на проверенной сборке:

```sh
# Уже отключены
com.toofifi.lineserver
com.htc.hyk_pcba
com.mphotool.usbcastserver

# Можно отключить, если не нужна встроенная заставка
adb shell pm disable-user --user 0 com.htc.screensaver
```

Не отключайте:

- `com.htc.magcubicos` — лаунчер и настройки изображения;
- `com.android.vending` — если это настоящий Play Store;
- `com.google.android.gms` — без него не будет Play и части push;
- `com.android.networkstack` — останетесь без сети.

## Практические советы

- Держите 1–2 приложения в фоне, а не десять.
- После установки тяжёлого приложения перезагрузите проектор: zram не всегда успевает разгрузиться.
- Для видео используйте аппаратное декодирование (VLC/mpv/MX Player), а не программное.
- Не ставьте лаунчеры с тяжёлыми анимациями и виджетами.
- Для кино на 1080p 2 ГБ достаточно; для браузера с множеством вкладок — нет.
- Если приложение выгружается при переключении, проверьте `dumpsys meminfo` и `logcat | grep -i lmkd`.

## Ограничение памяти на процесс (по желанию)

В HY300 Pro для этого есть модуль `memcap` через cgroup v1. На HY350 Max он не проверялся. Если хотите повторить, сначала проверьте, какие cgroup доступны:

```sh
adb shell ls /sys/fs/cgroup
adb shell cat /proc/cgroups
```

Не применяйте чужие лимиты вслепую: на другой сборке ядро и cgroup могут отличаться.
